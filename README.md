# Python Day 09 - If Elif Else Statements

## Overview

This repository contains 15 beginner-friendly Python programs demonstrating the use of `if-elif-else` statements.

## Programs Included

1. Student Grade Calculator
2. Traffic Signal Checker
3. Temperature Status
4. Mobile Battery Status
5. Internet Speed Category
6. Salary Category
7. ATM Balance Category
8. BMI Category
9. Electricity Bill Category
10. Driving Speed Checker
11. Exam Result
12. Laptop Category
13. Shopping Discount
14. Fuel Level Indicator
15. Restaurant Rating System

## Technologies Used

- Python 3
- Visual Studio Code

## Learning Outcomes

- Understand `if-elif-else`
- Build multiple decision-making programs
- Improve logical thinking
- Practice real-world conditional statements
